# 旅のプランナー

旅行ごとに「日ごとの予定」と「行きたい場所リスト」を作って編集できる、ブラウザで動く旅行計画アプリです。

- Claude と一緒に作成
- 形式：HTML・CSS・JavaScript だけで動く1ページのアプリ。ビルドもサーバーも不要

## 開き方

`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけです。

- 最初に開いたときは、架空のサンプル旅行が1件入ります（`sample-data.js`）
- 書いた内容は、そのブラウザの `localStorage`（キー `planner-local`）に保存されます
- サンプルに戻したいときは、開発者ツールで `localStorage.removeItem("planner-local")` を実行してから再読み込みしてください

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（CSS と JavaScript も全部この中） |
| `sample-data.js` | 架空のサンプルデータ（京都 2泊3日） |
| `SPEC.md` | 機能の仕様、データの形、ルール |
| `DEVIN_PROMPT.md` | AI（Devin など）に作業を頼むときの依頼文のひな形 |

## 主な機能

- 旅行の一覧・作成・編集・削除（上のバーのメニューで切り替え）
- 日程：日ごとの予定の追加・編集・並べ替え・削除、都市名とメモ、時間順に並べる
- 行きたい場所：★で優先度、都市で絞り込み、「日程に入れる」で好きな日の予定にする
- 時間は［◯時］［◯分（15分ごと）］で選ぶ。移動中・初日の到着前・最終日の帰りの出発後には予定を入れられない
- 操作の取り消し（元に戻す）

詳しくは `SPEC.md` を見てください。
